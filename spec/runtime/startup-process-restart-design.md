Parent accepts exactly one connection and verifies hello role/lane, observed pid equal actual Child.id, positive observed owner and loopback port. Directory ownership is the trusted fixture boundary, not an adversarial same-UID authentication claim. Only owned socket/child paths may be cleaned up.

Replies contain only pure role/phase/progress/owner/count/boolean facts and one fixed capture basename; no grant, Snapshot, authority row or native output goes over control IPC.
